# Market Watch V1.8

Version de test autonome pour valider les champs Mini/Maxi.

- `index.html` contient tout le HTML/CSS/JS.
- Les champs Mini/Maxi sont de vrais inputs HTML.
- Modification en direct sans rerender du champ.
- Cadre rouge sous mini, vert au-dessus maxi, aucun cadre entre les deux.
- Simulation toutes les 5 secondes.

Lancer avec un serveur HTTP pour tester la PWA : `python3 -m http.server 8080`
